# INSEAD CIAM Profile Hub Mockup

Responsive concept mockup for the proposed INSEAD.edu **My Profile and Access** landing page.

The concept presents a profile-first authenticated experience with:

- A Knowledge-inspired editorial hero and clear **My INSEAD** category marker
- Profile readiness and secure account-management actions
- Entitlement-aware cards for ePortal, Application Online, Intrepid and Study
- Account support, privacy and sign-in guidance
- Responsive desktop and mobile layouts

## Preview

Open `index.html` in a browser. The mockup is self-contained apart from the included official digital roundel image.

## Status

Design concept for CMS and stakeholder discussion. Links and account interactions are illustrative.
